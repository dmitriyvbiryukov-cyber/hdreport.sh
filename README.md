# Server Passport

Небольшой shell-скрипт для сбора информации о Linux- и FreeBSD-серверах.

Собирает технические сведения о системе, оборудовании, дисках, файловых системах, сети, службах, процессах и установленных пакетах. Результат — текстовый отчёт, своего рода паспорт сервера.

## Зачем

Чтобы быстро получить общее представление о сервере, не выполняя вручную десятки команд.

Отчёт можно использовать, чтобы:

- разобраться в незнакомом сервере;
- получить исходные данные для диагностики;
- передать информацию другому администратору;
- приложить отчёт к запросу в ChatGPT или другую ИИ-систему;
- сравнить конфигурации нескольких серверов;
- сохранить текущее состояние для последующего сравнения.

## Запуск

Скачать скрипт из репозитория:

```sh
curl -fsSL "https://raw.githubusercontent.com/dmitriyvbiryukov-cyber/hdreport.sh/refs/heads/main/hdreport.sh" -o hdreport.sh
chmod +x hdreport.sh
```

Полный отчёт:

```sh
./hdreport.sh
```

Краткая сводка:

```sh
./hdreport.sh --quick
```

Сохранить отчёт в файл:

```sh
./hdreport.sh > server-report.txt
```

Информация только об оборудовании:

```sh
./hdreport.sh --section hardware
```

Справка:

```sh
./hdreport.sh --help
```

Для получения максимально полной информации рекомендуется запускать от root.

## Что собирается

- **System** — ОС, ядро, hostname, uptime.
- **Hardware** — CPU, память, BIOS, материнская плата, PCI-устройства.
- **Storage** — диски, RAID, ZFS.
- **Filesystem** — файловые системы и использование места.
- **Network** — интерфейсы, IP-адреса, маршруты.
- **Services** — службы.
- **Applications** — установленное серверное ПО.
- **Processes** — запущенные процессы.
- **Packages** — установленные пакеты.
- **Security** — доступная системная информация по безопасности.

Доступность отдельных сведений зависит от ОС, оборудования и установленных системных утилит.

## Использование с ИИ

Отчёт можно загрузить в ChatGPT и попросить:

- описать архитектуру сервера;
- найти потенциальные проблемы;
- оценить дисковую и сетевую конфигурацию;
- выявить устаревшие компоненты;
- предложить варианты модернизации;
- сравнить несколько серверов.

Таким образом, Server Passport позволяет быстро передать ИИ технический контекст реальной инфраструктуры, а не описывать сервер вручную.

## Особенности

- Linux и FreeBSD, включая старые версии FreeBSD.
- POSIX shell (`sh`).
- Не требует установки дополнительных зависимостей.
- Не изменяет конфигурацию сервера.
- Не устанавливает и не удаляет программы.
- Не отправляет данные куда-либо автоматически.

**Важно:** отчёт может содержать IP-адреса, имена пользователей, сведения о процессах и аргументы команд. Перед передачей третьим лицам проверьте его содержимое.
